# Énergie 3.26.0 — observations nutritionnelles affinées

- Les fruits, légumes, légumineuses, grains entiers, noix et graines sont maintenant reconnus comme sources possibles de fibres.
- L’estimation nutritionnelle disponible pour un repas peut aussi confirmer la présence de protéines ou de fibres.
- Une catégorie n’est plus présentée comme une faiblesse uniquement parce qu’elle arrive dernière parmi quatre compteurs.
- Une suggestion alimentaire exige au moins 8 repas et une présence repérée dans moins de 30 % des repas.
- « Habitude observée » et « Suggestion principale » utilisent des signaux distincts afin d’éviter la répétition.
- Lorsqu’aucune priorité claire ne ressort, l’application le dit explicitement au lieu de forcer une recommandation.
- Les formulations parlent d’aliments « repérés dans les descriptions » afin de respecter les limites d’une analyse automatisée.
