# Énergie 3.29.6 — lecture hebdomadaire et plein écran

- Les dates sont maintenant identifiées clairement comme des débuts de semaine.
- Une explication précise que les deux courbes regroupent des journées différentes d’une même semaine.
- Le glissement horizontal dans le graphique n’active plus le changement d’onglet.
- Le bouton « Agrandir le graphique » ouvre une vue plein écran horizontale.
- Le bouton « Revenir au suivi » ferme la vue et rétablit l’orientation normale lorsque possible.
