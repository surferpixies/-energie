# Énergie 3.22.0

## Recherche dans les ressentis

- Une barre de recherche est disponible dans les ressentis avant et après le repas.
- Le filtrage est instantané et ne tient pas compte des accents ni des majuscules.
- Les catégories contenant un résultat s’ouvrent automatiquement.
- Les ressentis déjà sélectionnés restent visibles et conservent leur score pendant la recherche.
- Les compteurs sélectionnés/total demeurent inchangés.
- Un bouton permet d’effacer rapidement la recherche et les catégories retrouvent ensuite leur état précédent.
- Un message indique lorsqu’aucun ressenti ne correspond.
