# Énergie 3.56.25 — Correctif de largeur du formulaire

- Le dialogue de repas est maintenant strictement limité à la largeur de l’iPhone.
- Aucun contenu interne ne peut élargir le formulaire.
- Les favoris et derniers repas défilent seulement dans leur propre rangée.
- Le résumé des ressentis reste contenu dans sa carte.
- Aucun changement de base de données n’est requis.
