# Énergie 3.26.1 — favoris repliables dans le Profil

- La section « Mes favoris » du Profil est maintenant présentée dans un panneau repliable.
- Le panneau est fermé par défaut afin d’alléger la page.
- Le nombre de favoris demeure visible sans ouvrir le panneau.
- Le même comportement s’applique automatiquement aux quatre profils de démonstration.
