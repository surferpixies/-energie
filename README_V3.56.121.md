# Énergie v3.56.121

Cette version améliore l’estimation calorique sans modifier les repas déjà enregistrés.

- fractions usuelles et Unicode (`1/2`, `1 1/2`, `½`);
- quantités comptables (tranches, portions, bols, pots, paquets et morceaux);
- nombres d’aliments comme `2 œufs` ou `1/2 avocat`;
- portions petites et généreuses;
- quantités appliquées aux plats composés;
- conversion prudente des grammes lorsque le catalogue ne fournit qu’une portion courante;
- niveau de confiance abaissé lorsqu’une conversion de portion demeure approximative.

Les estimations manuelles existantes restent prioritaires. Aucun historique, ressenti ou fichier photo n’est migré.
