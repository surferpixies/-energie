# Énergie 3.29.0 — prototype du mode professionnel

- Un « Mode professionnel — Démo » est accessible depuis le Profil.
- Son ouverture demande immédiatement de choisir l’un des quatre clients fictifs.
- Le dossier sélectionné reprend toute la navigation du mode démo en lecture seule.
- La bannière professionnelle permet de changer rapidement de client ou de quitter le mode.
- L’onglet « Suivi » apparaît uniquement dans un profil démo ou dans le mode professionnel.
- Le professionnel peut créer des notes partagées ou privées avec horodatage.
- Les notes peuvent être rattachées à un repas, une journée, l’hydratation, le sommeil, l’activité ou une observation globale.
- Le professionnel voit les notes partagées et privées; le client démo voit uniquement les notes partagées, en lecture seule.
- Des notes fictives initiales permettent de tester immédiatement les deux perspectives.
- Toutes les notes de ce prototype restent locales et séparées de Supabase.
