# Énergie 3.56.19 — Boissons et hydratation

- La saisie rapide du sommaire ajoute toujours immédiatement 500 ml d’eau.
- La vue détaillée propose maintenant « Ajouter une boisson ».
- Chaque boisson possède un type, une heure et une quantité modifiable.
- Types disponibles : eau, eau pétillante, café, thé, tisane, jus, lait, boisson gazeuse, boisson énergisante, bière, vin, spiritueux et autre.
- Le café, le thé et certaines boissons permettent de préciser la présence de caféine.
- Les boissons alcoolisées sont identifiées séparément.
- Seules l’eau et l’eau pétillante remplissent l’objectif d’eau.
- Les boissons inscrites peuvent être supprimées individuellement.
- Les nouvelles données sont synchronisées dans le JSON quotidien existant; aucun changement SQL n’est requis.
