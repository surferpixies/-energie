# Énergie 3.27.0 — fibres et protéines mieux reconnues

- Les fruits, légumes, légumineuses, grains entiers, noix et graines reconnus comptent maintenant comme sources de fibres dans l’estimation nutritionnelle.
- Une valeur prudente de fibres est estimée par portion courante lorsque la fiche détaillée de l’aliment n’en possédait pas.
- Les légumes reconnus empêchent désormais la suggestion automatique d’ajouter des fibres au repas.
- Le prosciutto est reconnu comme source de protéines et de sodium.
- La faute courante « proscuitto » est également reconnue.
- Les catégories alimentaires reconnues participent maintenant directement aux indicateurs de protéines, de légumes, de fruits et de fibres.
