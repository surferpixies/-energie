# Énergie 3.56.21 — Formulaire de repas allégé

- Les ressentis avant sont remplacés dans le formulaire par une petite carte résumée.
- Le bouton « Ajouter » ou « Modifier » ouvre une fenêtre dédiée aux ressentis avant.
- Les choix de cette fenêtre restent dans le même brouillon automatique du repas.
- Les ressentis après utilisent eux aussi une carte compacte et leur fenêtre dédiée existante.
- L’heure et la description du repas apparaissent maintenant avant les favoris et les raccourcis.
- La zone « Ce que tu as mangé ou bu » est davantage mise en évidence.
- Les résumés Avant et Après montrent les choix déjà consignés sans réafficher toutes les options.
- Aucun changement de base de données n’est requis.
