# Énergie v3.56.81

## Quantités dans la description des repas

- Le champ de description suggère maintenant d’ajouter les quantités lorsque l’utilisateur les connaît.
- Exemples : `150 g de poulet`, `1 tasse de riz`, `1 tasse de brocoli`.
- La saisie demeure entièrement facultative.
- L’estimation nutritionnelle ajuste maintenant les valeurs lorsqu’une quantité saisie utilise la même unité mesurable que la portion de référence de la base alimentaire (g/kg, ml/l, tasse/cup, c. à soupe, c. à thé).
- Si la quantité n’est pas comparable de façon fiable à la portion de référence, Énergie conserve l’estimation par portion courante plutôt que d’inventer une conversion.
- Aucun changement au stockage ou à la logique des ressentis à suivre.
