# Énergie 3.20.2

## Compteur visible des ressentis

- Chaque catégorie affiche désormais le nombre sélectionné sur le nombre disponible, par exemple **3**/9.
- Le nombre sélectionné est en gras afin d’être repérable rapidement.
- Le compteur se met à jour immédiatement lors d’une sélection ou d’un retrait, même avant la sauvegarde.
- Les sélections demeurent donc visibles lorsque la catégorie est refermée.
