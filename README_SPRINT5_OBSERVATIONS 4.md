# Énergie V3.12.0 — Sprint 5

Ajoute un moteur indépendant d’observations personnalisées : sommeil ↔ énergie, hydratation ↔ énergie, déjeuner ↔ énergie et associations prudentes entre certaines familles alimentaires et les symptômes consignés.

Chaque carte affiche un stade, un niveau de confiance et une section « Pourquoi le Cerveau pense cela? ».

Garde-fous : deux groupes comparables, minimum de données, écarts faibles ignorés, aucune formulation diagnostique. Aucun nouveau script SQL n’est requis.
