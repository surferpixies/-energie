# Énergie v3.56.82 — Éléments reconnus facultatifs

- Ajout dans **Profil > Préférences de l’application** d’un réglage « Afficher Éléments reconnus ».
- Le réglage est activé par défaut afin de préserver le comportement existant.
- Lorsqu’il est désactivé, la petite carte Éléments reconnus est masquée pendant la saisie d’un repas.
- L’analyse interne du repas et les estimations nutritionnelles continuent de fonctionner : seul l’affichage de la carte est masqué.
- Aucun changement à la structure, au stockage ou à la logique des **ressentis à suivre**.
