# Énergie v3.56.87

- Une photo analysée avec succès par l’IA passe à « ✓ Photo analysée ».
- Le bouton IA est alors désactivé pour empêcher les appels répétés accidentels sur la même photo.
- Si l’analyse échoue, le bouton reste disponible pour réessayer.
- Même comportement pour les repas et les collations.
- Aucun changement au stockage ni à la logique des ressentis à suivre.
