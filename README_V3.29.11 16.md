# Énergie 3.29.11 — parcours soya plus démonstratif

- Le profil d’Élodie commence avec des réactions plus importantes.
- La tendance monte durant les premières semaines, se stabilise, puis diminue fortement.
- Les expositions possibles au soya diminuent à partir du moment où le motif devient visible.
- Une ligne « Tendance remarquée — réduction du soya » situe ce changement dans la chronologie.
- Les semaines incomplètes de moins de quatre jours sont exclues du graphique.
