# Énergie 3.23.0 — saisie rapide des repas

- Les favoris compatibles avec le type de repas apparaissent maintenant dès l’ouverture du formulaire.
- Un toucher sur un favori remplit immédiatement la description et les notes.
- Les repas récents remplissent maintenant le champ au lieu de s’ajouter à un texte existant.
- Un bouton clair permet d’ajouter ou de retirer le repas des favoris avant l’enregistrement.
- L’étoile du Journal indique désormais visuellement si un repas est déjà favori.
- Les photos, notes et valeurs nutritionnelles sont regroupées dans une section facultative fermée par défaut pour alléger la saisie.
- Les favoris de dîner et de souper continuent de partager la même banque.
