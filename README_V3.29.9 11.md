# Énergie 3.29.9 — semaines du dimanche et paysage automatique

- Les semaines vont maintenant du dimanche au samedi.
- Chaque semaine possède sa propre date sur l’axe horizontal.
- L’espacement horizontal augmente automatiquement selon le nombre de semaines.
- Le bouton annonce clairement l’ouverture en mode horizontal.
- L’app verrouille l’orientation paysage lorsque le navigateur le permet.
- Une rotation visuelle automatique prend le relais sur les appareils qui refusent ce verrouillage.
