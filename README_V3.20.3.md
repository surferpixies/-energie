# Énergie 3.20.3

## Rafraîchissement immédiat du repas

- Après l’enregistrement des ressentis, le résumé affiché dans « Modifier le repas » est actualisé immédiatement.
- Le nombre de ressentis après apparaît donc sans devoir enregistrer, fermer puis rouvrir le repas.
- Le bouton conserve son état et son libellé « Modifier les ressentis après ».
