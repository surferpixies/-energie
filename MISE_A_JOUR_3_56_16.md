# Énergie 3.56.16 — Compteur de repas cohérent

- Le compteur des calories correspond maintenant aux repas réellement visibles dans le Journal.
- Une ancienne entrée dupliquée d’un repas principal ne peut plus créer un faux « 3/3 » ni gonfler le total calorique.
- Toutes les collations réellement enregistrées continuent d’être comptées.
- Aucune donnée existante n’est supprimée automatiquement.
- Aucun changement de base de données n’est requis.
