# Énergie 3.56.23 — Formulaire de repas réorganisé

- L’heure est intégrée dans la carte du type de repas.
- Le ressenti avant reste visible sur plusieurs lignes sans coupure.
- Les raccourcis, favoris et derniers repas précèdent la saisie du repas.
- Les raccourcis de copie sont plus compacts.
- Les éléments reconnus suivent directement la saisie.
- La raison de manger précède une carte Calories plus discrète.
- Le ressenti après reprend la présentation compacte du ressenti avant.
- La note facultative est placée seule à la toute fin.
- Aucun changement de base de données n’est requis.
