# Énergie 3.29.1 — client visible dans la bannière professionnelle

- Le nom et l’icône du client sélectionné occupent maintenant le titre principal de la bannière.
- « Mode professionnel · Démo » apparaît directement sous son nom.
- Ces informations restent visibles sur mobile, contrairement à l’ancien texte secondaire.
- Le changement de client actualise immédiatement la bannière.
