# Énergie 3.30.1 — champs de date et icône grossesse

- Empêche les champs de date de dépasser horizontalement sur mobile.
- Réduit légèrement leur typographie et leur espacement sur les petits écrans.
- Affiche une icône de bébé lorsque le contexte Grossesse est sélectionné.
- Conserve la lune pour le cycle menstruel et lorsque le contexte est désactivé.
