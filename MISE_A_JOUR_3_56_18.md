# Énergie 3.56.18 — État des repas dans Ajout rapide

- Les repas principaux déjà remplis affichent une coche verte dans la fenêtre « Ajout rapide ».
- Toucher un repas rempli ouvre son entrée existante pour la modifier.
- Le dîner affiche un sablier avant 11 h et le souper avant 16 h lorsqu’ils ne sont pas encore remplis.
- Le sablier est uniquement informatif : le repas demeure accessible.
- Pour une journée passée, les repas non remplis affichent directement le « + ».
- Les en-cas conservent toujours le « + » et la mention « Plusieurs possibles ».
- Aucun changement de base de données n’est requis.
