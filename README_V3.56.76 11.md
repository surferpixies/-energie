- L’ouverture/fermeture d’une carte ne déclenche plus l’écran de chargement d’Observations.
- « Montre-moi autre chose » remplace seulement le contenu de la carte concernée.

- Le cache local de cette exploration est réinitialisé lors d’un vrai rerendu d’Observations (changement de date, données, etc.).
- Le moteur d’analyse restauré en 3.56.75 est conservé tel quel.
