# Énergie v3.56.99 — fiabilité des photos

- Une photo téléversée reçoit immédiatement une URL signée pour rester visible quand le repas est rouvert.
- Les repas contenant seulement un chemin Storage résolvent automatiquement leur URL d’affichage à l’ouverture.
- Les photos d’un brouillon de repas sont restaurées si l’interface est recréée après un aller-retour vers la caméra sur iPhone.
- L’ajout ou le retrait d’une photo déclenche la sauvegarde du brouillon.
- Aucun changement aux ressentis à suivre.
