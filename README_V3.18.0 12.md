# Énergie 3.18.0

- Les champs Date et Heure ont maintenant la même largeur compacte de 205 px.
- Le splash demeure affiché 1,5 seconde de plus afin de laisser le temps de lire.
- Les textes du splash sont plus grands, plus espacés et plus lisibles.
- Les messages « Saviez-vous que… » et les astuces tournent aléatoirement sans répétition pendant la même journée, jusqu’à ce que leur liste ait été parcourue.
