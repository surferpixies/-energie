# Énergie 3.23.2 — recherche des ressentis

- Une recherche affiche maintenant uniquement les ressentis correspondant au texte saisi.
- Les ressentis déjà sélectionnés mais sans correspondance sont temporairement masqués pendant la recherche.
- Ils restent sélectionnés et réapparaissent dès que la recherche est effacée.
