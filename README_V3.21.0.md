# Énergie 3.21.0

## Protection de la qualité des observations

- Un avertissement discret apparaît à partir de 8 ressentis sélectionnés.
- Une confirmation est demandée pour les combinaisons fortement atypiques : moitié ou plus de la liste, scores uniformes sur au moins 8 ressentis, ou apparition extrême d’au moins 8 ressentis après un repas.
- Une saisie confirmée comme exacte demeure incluse dans les observations.
- Une saisie dont l’utilisateur n’est pas certain peut être conservée dans le journal tout en étant temporairement exclue des analyses automatiques.
- Aucune saisie n’est supprimée automatiquement.
