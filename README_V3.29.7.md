# Énergie 3.29.7 — une courbe d’inconfort claire

- Le graphique utilise maintenant une seule courbe : le niveau moyen d’inconfort sur 5.
- L’axe horizontal affiche les semaines dans l’ordre chronologique.
- De petits indicateurs montrent le nombre de journées contenant l’élément suivi durant chaque semaine.
- Le bouton d’agrandissement est autorisé par le mode lecture seule.
- La vue plein écran conserve le retour vers le Suivi.
