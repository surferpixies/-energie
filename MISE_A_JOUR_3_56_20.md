# Énergie 3.56.20 — Hydratation complète dans le sommaire

- La carte Hydratation du mode sommaire affiche maintenant les gouttes de l’objectif quotidien.
- Toucher une goutte vide augmente directement le niveau d’eau.
- Toucher une goutte remplie redescend le niveau jusqu’à la goutte précédente.
- Le bouton « + Boisson » ouvre la même fenêtre de saisie que dans la vue détaillée.
- La carte ne modifie plus l’eau lorsqu’on touche simplement son arrière-plan.
- Le verre d’eau en filigrane demeure visible.
- Aucun changement de base de données n’est requis.
