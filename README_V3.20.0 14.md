# Énergie 3.20.0

Cette version remplace le score général « Énergie avant » par une comparaison détaillée des ressentis avant et après chaque repas.

- Le formulaire de repas propose la liste complète des ressentis avant, de façon facultative.
- Chaque ressenti sélectionné possède sa propre intensité de 1 à 5.
- À la première ouverture du ressenti après, les éléments choisis avant et leurs scores sont repris automatiquement.
- Après le repas, chaque élément peut être augmenté, diminué, retiré ou complété par un nouveau ressenti.
- Les ressentis avant sont propres à chaque repas : aucune sélection n’est reprise dans un autre repas ou une nouvelle journée.
- Les anciennes données d’énergie sont conservées pour compatibilité, mais aucune nouvelle valeur n’est demandée ni créée.
- La sauvegarde synchronisée conserve les scores avant et après dans le bloc de ressenti existant.
- Les observations alimentaires comparent maintenant les variations par ressenti plutôt qu’une énergie générale avant le repas.
