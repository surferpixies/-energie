# Énergie 3.28.1 — aperçu nutritionnel avant la sauvegarde

- Lorsque la détection automatique est activée, les valeurs nutritionnelles se remplissent pendant la saisie du repas.
- Un court délai évite de recalculer à chaque caractère.
- L’utilisateur peut vérifier et modifier l’estimation avant de sauvegarder.
- Les repas favoris et récents déclenchent eux aussi immédiatement l’aperçu.
- Une modification manuelle des valeurs empêche l’estimation automatique de les écraser.
- Le bouton « Estimer » permet de relancer volontairement le calcul.
- Le réglage automatique désactivé continue d’empêcher tout préremplissage automatique.
