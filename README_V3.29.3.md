# Énergie 3.29.3 — tendance professionnelle

- Le graphique apparaît en premier dans l’onglet Suivi d’Élodie.
- Il compare les réactions suivant du soya repéré aux périodes sans soya repéré.
- Il affiche les dates, les moyennes d’intensité et le nombre de journées d’exposition.
- Il rappelle clairement qu’une tendance observée n’est pas un diagnostic.
