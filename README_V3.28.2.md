# Énergie 3.28.2 — estimation visible lors d’un nouveau repas

- Lorsqu’une estimation automatique est trouvée, le panneau « Photo, notes et nutrition » s’ouvre automatiquement.
- Les valeurs sont ainsi visibles avant la première sauvegarde d’un repas ou d’une collation.
- Le bouton « Estimer » ouvre également le panneau lorsqu’il trouve une estimation.
- Aucun panneau ne s’ouvre lorsque la détection automatique est désactivée ou qu’aucune estimation fiable n’est trouvée.
