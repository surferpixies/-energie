# Énergie 3.23.1 — ressentis adaptés au moment

Les trois ressentis qui décrivent nécessairement une conséquence du repas sont maintenant proposés seulement après le repas :

- Rassasié
- Léger après le repas
- Faim rapidement après le repas

Ils restent disponibles dans les observations globales. Les autres ressentis digestifs demeurent accessibles avant et après afin de pouvoir comparer un symptôme déjà présent à son évolution.
