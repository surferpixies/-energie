# Énergie 3.25.0 — favori compact

- La grande carte des favoris a été retirée du formulaire.
- Une étoile apparaît maintenant à droite de « Ce que tu as mangé ou bu ».
- L’étoile est vide lorsque le repas n’est pas favori et pleine lorsqu’il l’est.
- Un toucher change l’état et affiche une courte confirmation discrète.
- Le changement est appliqué lors de l’enregistrement du repas.
- Le bouton conserve un libellé complet pour les technologies d’assistance.
