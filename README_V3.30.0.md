# Énergie 3.30.0 — contexte physiologique dans Profil

- Ajoute une section repliée « Contexte physiologique » dans Profil.
- Choix facultatif entre aucun contexte, cycle menstruel et grossesse.
- Le cycle permet de conserver la date de début des dernières menstruations.
- La grossesse permet de conserver une date prévue d’accouchement facultative.
- Ces données ne modifient pas encore les analyses et ne sont jamais déduites automatiquement.
