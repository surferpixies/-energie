# Énergie 3.28.0 — estimation nutritionnelle automatique facultative

- Un nouveau réglage « Détecter automatiquement les estimations nutritionnelles » apparaît sous le réglage nutritionnel principal.
- Il est activé par défaut afin de préserver le comportement actuel.
- Il dépend du réglage « Estimation nutritionnelle » et devient indisponible lorsque celui-ci est désactivé.
- Lorsqu’il est activé, Énergie préremplit automatiquement les valeurs reconnues au moment de sauvegarder le repas.
- Toutes les valeurs estimées demeurent modifiables.
- Lorsqu’il est désactivé, l’utilisateur peut saisir les valeurs manuellement ou utiliser ponctuellement le bouton « Estimer ».
- La désactivation n’efface jamais les valeurs nutritionnelles déjà enregistrées.
